# TD-003：发布产物可读性与泄漏门禁

> **状态：** 2026-09-09 完成并从活跃技术债移除。

## 原问题

JS 已 bundle 且关闭 sourcemap，但未启用标准 minification；构建与 Release 在打包前也没有检查最终 `dist/` 的文件边界、源码地图、源码、调试残留和意外敏感常量。

## 完成内容

- `build.mjs` 启用 esbuild 标准 minification、tree shaking、无 sourcemap 和 `debugger` 清理，并在文件末尾保留第三方许可声明；不引入重度混淆或远程代码。
- 新增 `scripts/release-artifact-check.mjs`，以精确文件/目录白名单阻断源码、source map、特殊文件、调试语句、常见私钥/API token 格式、不可解析或仍可被标准压缩显著缩小的 JavaScript。
- 构建在复制全部静态资源后立即执行产物审计；现有 CI 与 Release 通过 `npm run verify` 复用同一门禁，另提供 `npm run audit:artifact` 独立复查。
- 新增正反例自动化测试；静态红绿灯同时锁定构建压缩、安全选项和构建后审计调用。

## 验证与剩余边界

2026-09-09 `npm run verify` 通过：治理检查、动态商店版号审计、45 项测试、类型检查、标准压缩构建与最终产物审计均成功。`src/background/service-worker.ts` 369 行的既有单一职责黄灯仍保留；TD-002 的真实 Chrome 验收不能由本次构建替代。当前协议必须交付客户端的固定解密材料未做伪装，其退出继续由 TD-004 跟踪。
