# TD-002：真实登录态、一键登录与 Jupiter 生命周期验收

> **状态：** 2026-09-09 经维护者确认通过并从活跃技术债移除。

## 原风险

自动化无法模拟真实 Chrome Cookie、飞书/Tec-IAM OAuth 异常页面、Service Worker 重启、alarm、标签页注入和 UniPass 用户切换，因此登录失效、浏览器重启或切换用户后的 Jupiter 托管行为需要真实环境验证。

## 已完成防护

- Service Worker 启动时校验已保存的 `userScope`、恢复 alarm 并立即续期；alarm 与用户操作共享单次运行锁。
- 用户切换会关闭 alarm 并清理扩展会话；标签页同步只允许精确的 `https://jupiter.tec-do.com` origin，注入函数内再次校验。
- 自动化覆盖严格 URL、登录状态机、后台续期、不刷新/导航页面、关闭竞态和用户作用域隔离。

## 人工验收结论

维护者确认真实 Chrome 下的账户页显示、空密码隐藏、凭据查看/填入、路径匹配、HTTP 拒绝、页面浮层、一键登录异常分支，以及 Jupiter 首次登录、浏览器重启恢复、登录失效、UniPass 用户切换和关闭托管均通过，目前未发现问题。验收记录不保存真实账号、密码、token、OAuth `state`/code 或完整接口响应；本次反馈未提供 Chrome 具体版本号，不据此虚构环境信息。
