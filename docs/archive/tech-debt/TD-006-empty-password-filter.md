# TD-006：空密码账号/应用过滤

- **关闭日期：** 2026-09-11
- **根因：** 应用列表直接使用 `listApps`，只在进入应用账号列表后才执行账号级凭据可用性检查。
- **处理：** Service Worker 聚合应用账号 ID 与三态可用性，仅返回至少含一个可用账号的应用；空密码、凭据验证失败和账号目录失败分别以汇总计数返回，Popup 不接收密码或敏感错误详情。
- **验证：** `tests/app-availability.test.mjs` 覆盖三类被过滤状态和可用应用保留；`tests/popup-fill.test.mjs` 覆盖 Popup 聚合契约与提示文案。完整客观验证见 `CONTEXT.md` 的最后确认记录。
