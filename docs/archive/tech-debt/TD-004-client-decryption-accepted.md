# TD-004：认证服务端化与客户端长期凭据退出

状态：Closed（2026-09-11）。

维护者决定当前继续使用客户端解密方案，不启动认证服务端化试点，也不再把缺少 UniPass/目标应用后端改造权限视为当前阶段阻断项。

接受的边界：

- `credential-core.wasm`、最短生命周期、用户主动触发、精确 HTTPS URL 和不持久化继续作为当前安全措施；
- 具备本机控制权、DevTools 或扩展调试能力的用户仍可能观察运行时明文或提取客户端协议材料；
- 该方案提高静态分析成本，但不构成对终端用户保密的认证边界。

如果未来重新推进服务端认证，应以新的用户需求、后端权限和版本化接口契约创建独立任务/ADR，重新定义单次会话、绑定、撤销、重放拒绝和回退验收，不直接恢复本条债务。
